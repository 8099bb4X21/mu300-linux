# IMS、VoLTE、VoNR 开关（2026-10-14）

网页“蜂窝 → 网络锁定”新增三个独立开关。行为与 E5 公共仓库对齐，使用 MU300 原有 Shell AT、异步任务与启动流程，没有引入 Python 依赖，也不需要重编内核。

- 控制“查看／控制卡槽”选择的 SIM，不切换上网卡，设置分别保存。
- 保留二次确认、切换卡槽后取消旧确认、互斥和错误提示。
- 配置跟随“开机自动应用”；正常平台路径在 AT 握手完成、射频开启和首次拨号之前回放。未配置时保持基带默认，不新增语音设置启动命令。
- 单独切换 IMS、VoLTE、VoNR，以及只有语音偏好的开机回放，均不执行 SFUN，不主动 ifup 或重拨。
- 网络模式、频段、小区的现有回放和晚期恢复流程保持原样；“清除全部蜂窝锁定”不删除或修改这三项语音偏好。

指令与用户提供的 `UniSocCellularUtils.kt` 对齐：VoLTE 使用 `AT+CAVIMS`，VoNR 使用 `AT+SP5GCMDS="set nr param",45,<0|1>`，查询 `"get nr synch_param",42`。IMS 总开关使用原厂 RIL 的 `AT+IMSEN=<0|1>`。

VoLTE、VoNR 回读不一致时不保存。IMS 必须获得明确 OK；部分固件只支持 IMSEN 设置、不支持读取，此时页面明确标识“本次已应用”，不冒充真实回读。记录只对本次启动有效，不用旧开机的缓存推断当前状态。单项查询不支持时，不隐藏其他网络锁定功能。

关闭 IMS 不能保证屏蔽传统网络的全部电话和短信；页面有对应说明。未改动用户的 IMS APN、NV、射频模式或当前 SIM 设置。

验证包括 dash／bash 下的锁定与异步任务测试、新增语音开关成功／失败、缺失 OK、回读不一致、双卡文件隔离、仅语音配置的启动入口与单次回放、无额外 SFUN、重置保留偏好，以及实际页面处理函数的二次确认和三语言检查。

没有进行 MU300 实机部署或真实 IMS／VoLTE／VoNR 通话验证。本次先提交公共代码，不重新编译、打包 MU300。

# mu300-smsfwd rewrite rules: one pattern===replacement per line, run in
# order, global. '#' starts a comment; lines without === are skipped.
# Pattern is Oniguruma (jq); replacement supports $1..$9 and \n.
# Applied to the SMS body itself before it is placed in a human-readable
# channel (DingTalk, SMTP, local SMS, WeCom). The generic webhook keeps the
# raw body. Sender, time and device decorations, and test/power text, are
# never rewritten.
# Examples:
# (验证|码|\d{4,8})===ABBCCC
